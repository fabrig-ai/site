Get started

Say how you work. Agents do the rest. Code holds the line.

fabrig is a reliable, scalable and flexible agent-based software factory. temper, its first part, writes the code. Tell it how you build, from one person approving every change to goals that land on their own. Ask it where things stand, and why.
